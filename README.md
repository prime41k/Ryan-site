# rayan41k · personal site

Личный сайт-визитка. Тёмная тема, RU/EN, интерактивный плейграунд.

- hero с постоянно морфящейся фигурой
- перетаскиваемые вершины с live-координатами, площадью и периметром
- волна y = A·sin(f·x + t·v) на слайдерах
- квиз с цветовой пульсацией (зелёный/красный)
- «мой путь» — раскрывается шаг за шагом

## Как включить сайт (GitHub Pages)
1. Открой **Settings → Pages**
2. Source: **Deploy from a branch** → ветка `main`, папка `/ (root)`
3. Сохрани — через минуту сайт будет на `https://prime41k.github.io/Ryan-site/`

Весь сайт — один файл `index.html`, без сборки и зависимостей.
