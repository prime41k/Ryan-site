# rayan41k · personal site v2

Личный сайт-визитка. Один файл, без зависимостей, ~5000 строк.

## Секции

- **preloader** — загрузочный экран с прогрессом
- **hero** — тройной морфинг-блоб + орбиты + глитч-возраст (10–34) + typewriter
- **ticker** — две бегущие строки стека
- **stats** — анимированные счётчики (13 репо · 4 языка · 24/7 · 365)
- **about** — 6 карточек с SVG-иконками (feather-style)
- **stack** — анимированные skill-бары + облако инструментов
- **projects** — все 13 публичных репозиториев GitHub с фильтрами по языку и 3D-tilt
- **playground** — живые вершины (координаты/площадь/периметр) + волна y = A·sin(f·x + t·v)
- **path** — таймлайн из 7 шагов
- **now** — 6 радиальных прогресс-колец «что учу сейчас»
- **facts** — аккордеон фактов
- **contact** — кнопки + живой терминал с печатающимися командами
- **easter eggs** — matrix mode: кнопка в шапке, Konami-код, 5 кликов по логотипу

## Анимации

Скролл-прогресс, кастомный курсор, частицы-созвездия на фоне, reveal-on-scroll,
счётчики, tilt-карточки, magnetic-кнопки, ripple, глитч имени, морфинг, орбиты,
marquee, shimmer на барах, ping-точки — всё нативно, без библиотек.

## Запуск (GitHub Pages)

2. Source: **Deploy from a branch** → `main` / `(root)`
3. Сайт: `https://prime41k.github.io/Ryan-site/`
